# Сальдо

Личный учёт финансов в рублях. Сальдо работает в браузере и устанавливается на Android как приложение. После первого открытия с интернетом операции, статистика, расписания и резервные копии доступны офлайн. Учётная запись внутри приложения не нужна.

## Установка на Android

1. Скачайте APK последнего выпуска. [GitHub Releases](https://github.com/1mqt3/Saldo/releases/latest)
2. Откройте скачанный файл и подтвердите установку. Если Android предложит разрешить установку для Chrome или приложения «Файлы», включите разрешение для того приложения, из которого открыли APK.
3. Если вы вели учёт в PWA, выберите там **Ещё → Экспорт данных**. В установленном приложении выберите **Ещё → Импорт данных**, откройте полученный JSON и подтвердите восстановление.

Приложение проверяет обновления при запуске. В **Ещё → Обновления** видна установленная версия, а кнопка **Проверить обновления** запускает проверку вручную. Перед запуском установщика приложение сохраняет локальную копию. При необходимости её можно открыть через **Ещё → Копия перед обновлением**. Жест «Назад» закрывает текущее окно или возвращает к предыдущему экрану.

### Установка версии из Chrome

1. Откройте HTTPS-адрес приложения в Chrome с включённым интернетом и дождитесь экрана «Обзор».
2. В меню Chrome ⋮ выберите «Установить приложение» или «Добавить на главный экран» → «Установить». Эта же команда есть в разделе «Ещё», если браузер поддерживает установку.
3. Запускайте «Сальдо» значком на главном экране. Для проверки выключите интернет и откройте приложение ещё раз.

## Как вести учёт

- **Добавить расход.** Нажмите **+**, введите сумму и нажмите **Добавить операцию**. Подставляются сегодняшняя дата и последняя категория расхода. Чтобы ввести доход, выберите «Доход». Дату и заметку можно раскрыть отдельно.
- **История.** Откройте «Операции», выберите месяц и нажмите на запись, чтобы изменить или удалить её.
- **Баланс и статистика.** Баланс на «Обзоре» учитывает все операции по сегодняшний день. Доходы, расходы и диаграмма на этом экране относятся к выбранному месяцу. В «Статистике» можно выбрать день, неделю, месяц или год.
- **Категории.** В «Ещё» → «Категории расходов» можно создать категорию. Кнопка «Редактировать категории» в блоке расходов или доходов открывает список всех категорий. Выберите любую, чтобы изменить название, цвет, значок или удалить её. В окне подтверждения указано, куда перейдут связанные операции и регулярные платежи.
- **Регулярные платежи.** В «Ещё» → «Регулярные платежи» добавьте расписание. При открытии приложение запишет наступившие операции. Пауза пропускает даты до возобновления. Удаление расписания сохраняет историю.
- **Резервные копии.** В «Ещё» выберите «Экспорт данных» и сохраните JSON-файл. Чтобы перенести данные на другой телефон или адрес приложения, выберите «Импорт данных». Восстановление копии «Сальдо» заменяет данные после подтверждения. Операции автоматически между устройствами не синхронизируются.
- **Импорт из MoneyManager.** В «Ещё» → «Импорт данных» выберите JSON-экспорт с доходами и расходами в рублях. Операции добавятся в журнал, а повторный импорт пропустит уже загруженные записи. Названия счетов сохраняются в заметках. Импорт учитывает суммы, даты и категории, а фотографии остаются в исходном файле.

Браузер хранит журнал в IndexedDB. Сохраните резервную копию перед очисткой данных браузера или сменой телефона.

## Бесплатное размещение на GitHub Pages

1. Загрузите исходники в публичный репозиторий GitHub, сохранив структуру папок и файл `.github/workflows/pages.yml`.
2. Откройте **Settings → Pages → Build and deployment**, выберите **GitHub Actions** в поле **Source**.
3. Откройте **Actions → GitHub Pages → Run workflow**. После успешного запуска адрес появится в **Settings → Pages**.

Репозиторий содержит код. Записи пользователя не попадают в репозиторий или на GitHub Pages. GitHub-аккаунт нужен тому, кто размещает приложение. Для использования опубликованной GitHub Pages версии достаточно ссылки.

## Выпуск подписанного APK

При изменениях приложения в ветке `main` GitHub Actions собирает APK, подписывает его и публикует в Releases. Номер запуска этого процесса используется как `versionCode`, а имя версии вычисляется как `1.0.(versionCode - 1)`. В описании выпуска отображаются сообщения коммитов с предыдущего релиза.

Владелец репозитория один раз добавляет два Repository secrets в **Settings → Secrets and variables → Actions**. [Открыть настройки секретов](https://github.com/1mqt3/Saldo/settings/secrets/actions)

- `ANDROID_KEYSTORE_BASE64` — содержимое отдельного файла с Base64 зашифрованного хранилища ключа PKCS#12.
- `ANDROID_KEYSTORE_PASSWORD` — пароль этого хранилища, переданный отдельно.

Зашифрованный файл `.p12` храните как резервную копию ключа, а пароль сохраните отдельно в менеджере паролей. APK подписываются ключом с псевдонимом `saldo`. GitHub Actions сверяет отпечаток сертификата с `android/signing-certificate.sha256`. Когда секреты ещё не настроены, GitHub собирает проверочный unsigned APK и пропускает выпуск.

У Android-версии фиксированный `applicationId` `io.github.mqt3.saldo` и локальный адрес WebView `https://localhost`. Они сохраняют IndexedDB между обновлениями. Первая миграция базы сохраняет предыдущий журнал отдельным снимком. Сборка APK включает интерфейс, значки и шрифты, поэтому учёт и резервное копирование доступны офлайн.

## Локальная проверка

Требуется Node.js 22 или новее.

```sh
npm ci
npm test
npm run build
npm run preview
```

Команда `npm run dev` запускает режим разработки. Service worker включён в production-сборке. Для установки на телефоне используйте HTTPS. Для проверки на компьютере можно использовать `localhost`.
